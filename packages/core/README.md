# Flap Lab Core

TypeScript automata, grammar, parser, conversion, regular-expression, pumping-lemma, and L-system APIs used by Flap Lab.

Build with `npm run build --workspace=flap-lab-core` and test with `npm test --workspace=flap-lab-core` from the repository root.
